      Which sharpness do I want?

      A PDF page is drawn with lines and letters, not pixels, so it can be rasterised at any size. 2× is the honest default — it reads well on screen and prints acceptably. Reach for 3× or 4× only if the picture is going to be printed or zoomed into; each step up roughly doubles the file size, and a page that hits the browser's canvas ceiling is quietly capped rather than failing.

      JPG or PNG?

      PNG keeps text and line art perfectly crisp and is the right choice for a document page. JPG is much smaller, which matters if you are sending several pages to someone, but it puts faint fuzz around letters — so use it for photographs, not for fine print.

      Nothing is uploaded

      There is no upload step to intercept and no server copy to leak. The reader, the fonts and the whole renderer are downloaded to your browser once and then run from your own device — you can disconnect from the internet after the page loads and it still works.
